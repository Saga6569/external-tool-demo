# React Frontend для ExternalToolset Demo

## Запуск
1. Установите зависимости:
   npm install
2. Запустите dev сервер:
   npm run dev
3. Откройте браузер на http://localhost:5173

## Как работает фронтенд

Фронтенд имитирует работу агента и внешнего инструмента. Он:
- показывает чат, где агент запрашивает инструмент;
- вызывает инструмент выбора файла в браузере;
- отправляет deferred call и результат в backend;
- отображает статус и шаги сценария.

Ключевые функции:
- `runAgent` (`src/Agent.js`) — формирует deferred call, отправляет его на backend,
  вызывает инструмент и отправляет результат обратно.
- `pollBackendResult` (`src/Agent.js`) — опрашивает backend на наличие результата.
- `tools.pickFile` (`src/tools.js`) — открывает системный диалог выбора файла и
  возвращает имя/размер (или ошибку при отмене).
- `App` (`src/App.jsx`) — UI: чат, шаги сценария, статус и лог событий.
